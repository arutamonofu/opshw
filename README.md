# opshw — MLOps Basics Homework

Учебный репозиторий по дисциплине **MLOps Basics**.  
Проект включает в себя реализацию модели линейной регрессии, модульную структуру, всестороннее тестирование (unit, metamorphic, property-based, smoke, e2e), версионирование данных (DVC), автоматизацию проверок (GitHub Actions CI) и **централизованный трекинг экспериментов с использованием MLflow**.

---

## 🚀 Быстрый старт

### 1. Установка окружения

Проект управляется через [`uv`](https://docs.astral.sh/uv/):

```bash
# Клонирование репозитория
git clone https://github.com/arutamonofu/opshw.git
cd opshw

# Установка всех зависимостей проекта и группы разработки
uv sync --all-groups
```

### 2. Запуск тестов и линтеров

```bash
# Проверка качества кода и форматирования с ruff
uv run ruff check
uv run ruff format --check

# Быстрые smoke-тесты
uv run pytest -m smoke -v

# Полный набор тестов с расчетом покрытия
uv run pytest --cov=opshw --cov-report=term-missing -v
```

## 📊 Экспериментальный трекинг с MLflow

В рамках лекции по MLOps Basics от ручного версионирования гиперпараметров через ветки Git (`exp/lr-0-01`, `exp/n-iter-50`) был осуществлен переход к централизованному трекингу экспериментов через **MLflow**.

### Что логируется в каждом запуске (run):
- **Параметры**:
  - `method`: метод обучения (`numerical` — градиентный спуск, `analytical` — аналитическое решение через псевдообратную матрицу).
  - `learning_rate`: скорость обучения.
  - `learning_iterations`: число итераций оптимизации.
  - `n_samples`: размер обучающей выборки.
- **Динамические метрики (по эпохам)**:
  - `loss`: значение среднеквадратичной ошибки (MSE) на каждом шаге `step=epoch` в цикле обучения.
  - `final_mse`: итоговая ошибка модели.
- **Стандартизированные метаданные команды (контракт воспроизводимости)**:
  - `git.commit`: хеш коммита в репозитории.
  - `git.branch`: текущая рабочая ветка.
  - `git.author`: автор коммита (имя и email).
- **Артефакты**:
  - `model/model_weights.json`: сохраненные параметры модели ($\theta$), метаданные и финальный лосс.
  - `plots/loss_curve.png`: график кривой сходимости (MSE от эпохи) для численного метода.

---

### Запуск обучения и экспериментов

Вы можете запускать обучение через встроенный CLI `opshw-train` или через модуль `python -m opshw.train`:

#### 1. Численный метод (градиентный спуск) с настройкой гиперпараметров:
```bash
# Базовый запуск (lr=0.01, 50 итераций)
uv run opshw-train --lr 0.01 --iters 50 --method numerical --run-name "lr_0.01_iter_50"

# Эксперимент с повышенным числом итераций для лучшей сходимости
uv run opshw-train --lr 0.01 --iters 200 --method numerical --run-name "lr_0.01_iter_200"

# Эксперимент с меньшей скоростью обучения
uv run opshw-train --lr 0.001 --iters 100 --method numerical --run-name "lr_0.001_iter_100"
```

#### 2. Аналитический метод (baseline):
```bash
uv run opshw-train --method analytical --run-name "analytical_baseline"
```

#### 3. Быстрый запуск обоих методов через скрипт:
```bash
uv run python gradient_descent.py
```

### Просмотр результатов в веб-интерфейсе MLflow UI

Для визуального анализа, сравнения метрик и просмотра артефактов запустите MLflow:

```bash
uv run mlflow ui --port 5000
```

Затем откройте в браузере: **`http://localhost:5000`**

В интерфейсе доступны:
1. **Experiments list**: эксперимент `linear_regression` объединяет все запуски.
2. **Сравнение запусков (Compare Runs)**: сопоставление влияния гиперпараметров (`learning_rate`, `iterations`) на итоговую метрику `final_mse`.
3. **Графики сходимости**: динамика метрики `loss` по эпохам для каждого численного запуска.
4. **Артефакты**: просмотр и скачивание файлов `model_weights.json` и `loss_curve.png`.
